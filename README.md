# Ремонтная мастерская «СЕВЕР» 

## Запуск проекта

Проект использует локальную базу данных SQLite, поэтому для запуска не требуется устанавливать СУБД.

1. Клонируйте репозиторий:
   git clone <URL_вашего_репозитория>
   cd repairshop

2. Создайте и активируйте виртуальное окружение:
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   (Для macOS/Linux: source .venv/bin/activate)

3. Установите зависимости:
   py -m pip install -r requirements.txt

4. Примените миграции для создания базы данных:
   py manage.py migrate

5. Создайте суперпользователя (администратора) для доступа к панели управления:
   py manage.py createsuperuser

6. Запустите локальный сервер:
   py manage.py runserver

Сайт будет доступен по адресу: http://127.0.0.1:8000/
Админ-панель: http://127.0.0.1:8000/admin/

⚠️ **Важно:** Файл `db.sqlite3` добавлен в `.gitignore`. Это значит, что у каждого разработчика своя локальная база данных. Если вы склонировали проект, вам нужно создать своего суперпользователя и наполнить базу данными (услуги, запчасти) через админку.

## Функционал приложения

Приложение реализует ролевую модель доступа и включает три типа пользователей:

**Клиент:**
* Просмотр каталога услуг с ценами.
* Регистрация и авторизация в системе.
* Создание заявки на ремонт (с указанием типа устройства, описания неисправности и загрузкой фото).
* Личный кабинет с историей заявок и отслеживанием текущего статуса ремонта.

**Мастер:**
* Просмотр назначенных заявок (с фильтрацией по статусу).
* Изменение статуса ремонта (Принята, В диагностике, В ремонте, Готова к выдаче, Выдана).
* Добавление комментариев для клиента.
* Списание запчастей со склада и указание итоговой стоимости работ.

**Администратор:**
* Назначение заявок конкретным мастерам через панель управления.
* Управление пользователями, услугами и складом запчастей (через админ-панель Django).
* Просмотр страницы статистики с графиками (количество заявок, популярные услуги, выручка).

## Стек технологий

* **База данных:** SQLite
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (Chart.js)
